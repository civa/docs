## Provisioning

After purchase, your server goes through:

1. **AwaitingResourceCreation** - order received
2. **Deploying** - server being configured
3. **Active** - ready to use

Manage your servers in the [Dashboard](https://solami.fast/dashboard/dedicated-nodes).

## Add-ons

- **gRPC Addon** - add gRPC capability to your dedicated node at purchase time

## Features

- Unlimited RPS and sendTransaction/s
- Full network isolation
- Custom region selection
- Bare metal performance
- Dedicated support

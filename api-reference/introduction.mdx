## Base URLs

| Service   | Base URL                     |
|-----------|------------------------------|
| RPC       | `https://rpc.solami.fast/sol` |
| REST API  | `https://api.solami.fast`     |
| gRPC      | `https://grpc.solami.fast`    |
| WebSocket | `wss://rpc.solami.fast/ws/sol` |

## Authentication

All requests require an API key passed as a query parameter:

```
https://rpc.solami.fast/sol?api_key=YOUR_API_KEY
```

## RPC Methods

Solami supports the full Solana JSON-RPC specification. All requests use POST with a JSON-RPC 2.0 body:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "METHOD_NAME",
  "params": []
}
```

## REST API

The REST API at `https://api.solami.fast` provides authenticated endpoints for managing your account, API keys, billing, and usage.

All REST endpoints require authentication via your API key.

## Rate Limits

| Plan         | RPS   | sendTransaction/s |
|--------------|-------|--------------------|
| Free         | 5     | 1                  |
| Dev          | 50    | 5                  |
| Pro          | 200   | 20                 |
| Ultra        | 500   | 50                 |
| Shared Metal | 2,000 | 200                |

Rate-limited requests return HTTP `429 Too Many Requests`.

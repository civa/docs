---
title: "getMinimumBalanceForRentExemption"
description: "Returns the minimum lamports required for an account of a given size to be rent exempt."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getMinimumBalanceForRentExemption",
  "params": [50]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| length | usize | Account data length in bytes. Required. |
| config | object | Optional configuration object. |
| config.commitment | string | Commitment level (`processed`, `confirmed`, `finalized`). |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 1113600
}
```

The `result` field contains a `u64` value representing the minimum lamports required for rent exemption.

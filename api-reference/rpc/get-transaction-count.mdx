---
title: "getTransactionCount"
description: "Returns the total number of transactions processed by the cluster."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getTransactionCount",
  "params": [
    {
      "commitment": "finalized"
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| config | object | Optional configuration object. |
| config.commitment | string | Commitment level. |
| config.minContextSlot | u64 | Minimum slot for request evaluation. |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 268
}
```

The `result` is a `u64` representing the total transaction count.

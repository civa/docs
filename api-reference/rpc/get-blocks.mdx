---
title: "getBlocks"
description: "Returns confirmed block slots in a range."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getBlocks",
  "params": [5, 10]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| startSlot | u64 | Start slot (required) |
| endSlot | u64 | End slot (optional, max 500,000 slots above startSlot) |
| config | object | Optional configuration object |
| config.commitment | string | Commitment level: `confirmed` or `finalized` |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [5, 6, 7, 8, 9, 10]
}
```

- `result` - Array of u64 confirmed slot numbers within the requested range.

## Example

  -X POST \

    "id": 1,

    "params": [5, 10]

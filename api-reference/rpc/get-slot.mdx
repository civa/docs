---
title: "getSlot"
description: "Returns the slot that has reached the given or default commitment level."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getSlot",
  "params": [
    {
      "commitment": "finalized",
      "minContextSlot": 1000
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `commitment` | string (optional) | Commitment level: `processed`, `confirmed`, or `finalized` |
| `minContextSlot` | u64 (optional) | Minimum slot that the request can be evaluated at |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 1234
}
```

| Field | Type | Description |
|-------|------|-------------|
| `result` | u64 | Current slot |

## Example

<CodeGroup>
```bash cURL
curl "https://rpc.solami.fast/sol?api_key=YOUR_API_KEY" \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'
```

```javascript JavaScript
const response = await fetch("https://rpc.solami.fast/sol?api_key=YOUR_API_KEY", {
```

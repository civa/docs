---
title: "getBlockProduction"
description: "Returns block production statistics for validators."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getBlockProduction",
  "params": [
    {
      "commitment": "finalized"
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| config | object | Optional configuration object |
| config.commitment | string | Commitment level |
| config.identity | string | Validator pubkey to filter results for a single validator |
| config.range | object | Slot range to query |
| config.range.firstSlot | u64 | First slot of the range (required in range) |
| config.range.lastSlot | u64 | Last slot of the range (optional, defaults to current slot) |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": {
      "slot": 9887
    },
    "value": {
      "byIdentity": {
        "85iYT5RuzRTDgjyRa3cP8SYhM2j21fj7NhfJ3peu1DPr": [9888, 9886]
      },
      "range": {
        "firstSlot": 0,
        "lastSlot": 9887
      }
    }
  }
}
```

- `context.slot` - The slot at which the data was fetched.
- `value.byIdentity` - Dictionary keyed by validator pubkey. Each value is an array of `[assigned, produced]` slot counts.
- `value.range.firstSlot` - First slot of the block production range.
- `value.range.lastSlot` - Last slot of the block production range.

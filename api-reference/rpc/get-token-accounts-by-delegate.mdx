---
title: "getTokenAccountsByDelegate"
description: "Returns SPL Token accounts approved for a given delegate."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getTokenAccountsByDelegate",
  "params": [
    "9mMBg1qaUaQdht6Q7r5T5VirRzJbNAyquKTq96FyR4UC",
    { "mint": "Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr" },
    { "encoding": "jsonParsed" }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| pubkey | string | (required) Pubkey of the delegate account to query, as a base-58 encoded string. |
| filter | object | (required) Filter by `mint` (string) or `programId` (string). |
| config | object | (optional) Configuration object containing `commitment` (string), `encoding` (string), `dataSlice` (object), `minContextSlot` (number). |


- `pubkey` - Pubkey of the token account.
- `account.data.parsed.info.tokenAmount` - Total token balance of the account.
- `account.data.parsed.info.delegate` - The approved delegate address.
- `account.data.parsed.info.delegatedAmount` - Amount delegated to the delegate.

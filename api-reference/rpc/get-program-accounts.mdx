---
title: "getProgramAccounts"
description: "Returns all accounts owned by a program, optionally filtered."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getProgramAccounts",
  "params": [
    "TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA",
    {
      "encoding": "base64",
      "filters": [
        {
          "dataSize": 165
        }
      ]
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| pubkey | string | Base-58 encoded public key of the program. Required. |
| config | object | Optional configuration object. |
| config.commitment | string | Commitment level (`processed`, `confirmed`, `finalized`). |
| config.encoding | string | Encoding for account data: `base58`, `base64`, `base64+zstd`, or `jsonParsed`. |
| config.filters | array | Array of filter objects: `{"dataSize": usize}` or `{"memcmp": {"offset": usize, "bytes": string}}`. |
| config.dataSlice | object | Limit returned data with `offset` (usize) and `length` (usize) fields. |
| config.minContextSlot | number | Minimum slot at which the request can be evaluated. |
| config.withContext | boolean | Wrap the result in an RpcResponse with context. |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [
    {
      "pubkey": "CxELquR1gPP8wHe33gZ4QxqGB3sZ9RSwsJ2KshVewkFY",
      "account": {
        "data": ["KQAAAAAAAA...", "base64"],
        "executable": false,
        "lamports": 15298080,
        "owner": "4Nd1mBQtrMJVYVfKf2PJy9NZUZdTAsp7D4xWLs4gDB4T",
        "rentEpoch": 28,
        "space": 42
      }
    }
  ]
}
```

The result is an array of objects, each containing `pubkey` (the account address) and `account` (the account data including `data`, `executable`, `lamports`, `owner`, `rentEpoch`, and `space`).

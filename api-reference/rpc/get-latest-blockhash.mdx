---
title: "getLatestBlockhash"
description: "Returns the latest blockhash and its last valid block height."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getLatestBlockhash",
  "params": [
    {
      "commitment": "processed"
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| config | object | Optional configuration object. |
| config.commitment | string | Commitment level. |
| config.minContextSlot | u64 | Minimum slot for request evaluation. |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": {
      "slot": 2792
    },
    "value": {
      "blockhash": "EkSnNWid2cvwEVnVx9aBqawnmiCNiDgp3gUdkDPTKN1N",
      "lastValidBlockHeight": 3090
    }
  }
}
```

The `value` object contains `blockhash` (string) and `lastValidBlockHeight` (u64).

## Example

<CodeGroup>
```bash cURL
curl "https://rpc.solami.fast/sol?api_key=YOUR_API_KEY" \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "getLatestBlockhash",
    "params": [
      {"commitment": "processed"}
    ]
  }'
```

```javascript JavaScript
const response = await fetch("https://rpc.solami.fast/sol?api_key=YOUR_API_KEY", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    jsonrpc: "2.0",
    id: 1,
    method: "getLatestBlockhash",
    params: [{ commitment: "processed" }],
  }),
});
const data = await response.json();
```

---
title: "getBlockHeight"
description: "Returns the current block height."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getBlockHeight",
  "params": [
    {
      "commitment": "finalized"
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| config | object | Optional configuration object |
| config.commitment | string | Commitment level |
| config.minContextSlot | u64 | Minimum slot at which the request can be evaluated |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 1233
}
```

- `result` - Current block height as a u64.

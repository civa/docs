---
title: "getBlocksWithLimit"
description: "Returns confirmed block slots starting at a slot, up to a limit."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getBlocksWithLimit",
  "params": [5, 3]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| startSlot | u64 | Start slot (required) |
| limit | usize | Maximum number of blocks to return (required, max 500,000) |
| config | object | Optional configuration object |
| config.commitment | string | Commitment level: `confirmed` or `finalized` |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [5, 6, 7]
}
```

- `result` - Array of u64 confirmed slot numbers starting from the given slot, up to the limit.

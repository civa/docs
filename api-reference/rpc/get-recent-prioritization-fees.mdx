---
title: "getRecentPrioritizationFees"
description: "Returns recent prioritization fee samples."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getRecentPrioritizationFees",
  "params": [
    ["CxELquR1gPP8wHe33gZ4QxqGB3sZ9RSwsJ2KshVewkFY"]
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| addresses | array | Optional array of up to 128 base-58 encoded account addresses to filter by. |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [
    {
      "slot": 348125,
      "prioritizationFee": 0
    },
    {
      "slot": 348126,
      "prioritizationFee": 1000
    }
  ]
}
```

Returns an array of objects, each containing `slot` (u64) and `prioritizationFee` (u64) in micro-lamports.

---
title: "getLargestAccounts"
description: "Returns the 20 largest accounts by lamport balance."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getLargestAccounts",
  "params": [
    {
      "commitment": "finalized"
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| config | object | Optional configuration object. |
| config.commitment | string | Commitment level (`processed`, `confirmed`, `finalized`). |
| config.filter | string | Filter results by account type: `circulating` or `nonCirculating`. |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": {
      "slot": 54
    },
    "value": [
      {
        "address": "99P8ZgtJYe1buSK8JXkvpLh8xPsCFuLYhz9hQFNw93WJ",
        "lamports": 999974
      }
    ]
  }
}
```

The `value` field contains an array of objects, each with `address` (base-58 encoded public key) and `lamports` (balance).

---
title: "getTokenSupply"
description: "Returns the total supply of an SPL Token mint."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getTokenSupply",
  "params": ["Gh9ZwEmdLJ8DscKNTkTqPbNwLNNBjuSzaG9Vp2KGtKJr"]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| pubkey | string | (required) Pubkey of the token mint to query, as a base-58 encoded string. |
| config | object | (optional) Configuration object containing `commitment` (string). |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": { "slot": 1114 },
    "value": {
      "amount": "100000",
      "decimals": 2,
      "uiAmount": 1000,
      "uiAmountString": "1000"
    }
  }
}
```

- `amount` - Raw total supply without decimals, as a string.
- `decimals` - Number of base-10 digits to the right of the decimal place.
- `uiAmount` - Total supply as a float, accounting for decimals.
- `uiAmountString` - Total supply as a string, accounting for decimals.

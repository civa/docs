---
title: "getFeeForMessage"
description: "Returns the fee the cluster would charge for a given message."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getFeeForMessage",
  "params": [
    "AQABAgIAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAQAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAEBAQAA",
    {
      "commitment": "processed"
    }
  ]
}
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| message | string | Base-64 encoded message. Required. |
| config | object | Optional configuration object. |
| config.commitment | string | Commitment level. |
| config.minContextSlot | u64 | Minimum slot for request evaluation. |

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "context": {
      "slot": 5068
    },
    "value": 5000
  }
}
```

The `value` field is a `u64` fee in lamports, or `null` if the message is invalid.

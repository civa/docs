---
title: "minimumLedgerSlot"
description: "Returns the lowest slot in the node's ledger."
---

## Request

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "minimumLedgerSlot"
}
```

### Parameters

This method takes no parameters.

## Response

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": 1234
}
```

- `result` - The lowest slot in the node's ledger as a u64.

## Example

    "id": 1,

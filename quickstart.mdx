## 1. Create an Account

Sign up at [solami.fast](https://solami.fast) with your email.

## 2. Get Your API Key

Navigate to **Dashboard → API Keys** and create a key for the service you need:

- **RPC Key** - JSON-RPC and WebSocket access
- **gRPC Key** - Yellowstone gRPC streaming
- **SWQoS Key** - priority transaction landing via staked validators

## 3. Make Your First Request

<CodeGroup>
```bash cURL
curl "https://rpc.solami.fast/sol?api_key=YOUR_API_KEY" \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "getSlot"
  }'
```

```javascript JavaScript
const response = await fetch("https://rpc.solami.fast/sol?api_key=YOUR_API_KEY", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    jsonrpc: "2.0",
    id: 1,
    method: "getSlot",
  }),
});

const data = await response.json();
console.log("Current slot:", data.result);
```

```python Python
import requests

response = requests.post(
    "https://rpc.solami.fast/sol?api_key=YOUR_API_KEY",
    json={"jsonrpc": "2.0", "id": 1, "method": "getSlot"},
)

print("Current slot:", response.json()["result"])
```
</CodeGroup>

## Endpoints

| Service   | URL                                          |
|-----------|----------------------------------------------|
| RPC       | `https://rpc.solami.fast/sol?api_key={key}`  |
| gRPC      | `https://grpc.solami.fast?api_key={key}`     |
| WebSocket | `wss://rpc.solami.fast/ws/sol?api_key={key}` |
| REST API  | `https://api.solami.fast/sol?api_key={key}`  |
